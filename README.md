## 📦 Installation Options

### 1. H Panel

Installs the main panel and automatically:

* Downloads latest files
* Installs dependencies
* Installs Python requirements
* Creates a systemd service
* Starts `avm.py`
* Enables auto-start on reboot

### 2. H Panel Node

Installs a node and automatically:

* Downloads latest files
* Installs dependencies
* Installs Python requirements
* Creates a systemd service
* Starts `node.py`
* Enables auto-start on reboot

---

## ⚙️ Service Commands

### Panel

```bash
systemctl status avm
systemctl restart avm
systemctl stop avm
journalctl -u avm -f
```

### Node

```bash
systemctl status avm-node
systemctl restart avm-node
systemctl stop avm-node
journalctl -u avm-node -f
```
